# AGENTS.md

## Project Overview

This is a **Homebrew tap** for [`aws-sso-login`](https://github.com/witnsby/aws-sso-login), a CLI that streamlines AWS SSO authentication and credentials management.

The repo has two responsibilities:
1. **Host the Homebrew formula** (`Formula/aws-sso-login.rb`) so users can install the CLI via `brew install`.
2. **Auto-update the formula** via a Go script (`src/main.go`) that fetches the latest GitHub release, downloads each binary, computes its SHA256, and rewrites the formula file.

## Key Workflows

### Updating the Formula

The Go updater (`src/main.go`) does the following:
1. Calls the GitHub API to find the latest release of `witnsby/aws-sso-login`.
2. Downloads the four platform binaries (`darwin_amd64`, `darwin_arm64`, `linux_amd64`, `linux_arm64`).
3. Computes the SHA256 of each binary.
4. Regenerates `Formula/aws-sso-login.rb` with the new version, URLs, and checksums.

Run it locally:
```bash
make run        # go run ./src/main.go
```

### CI/CD

`build_release.yaml` triggers on every push to `main` and on `workflow_dispatch`. It:
1. Checks out the repo.
2. Runs `make run` (the Go updater).
3. Commits and pushes the updated formula back to `main`.

### Makefile Targets

| Target         | Purpose                                  |
|----------------|------------------------------------------|
| `install-deps` | `go mod tidy`                            |
| `build`        | Build the updater binary to `./tmp/`     |
| `run`          | Run the updater directly with `go run`   |
| `tests`        | Run Go tests                             |
| `cover`        | Run tests with coverage report           |

## Development Guidelines

- **Never edit `Formula/aws-sso-login.rb` by hand.** It is fully generated by `src/main.go`.
- All logic for fetching releases and computing checksums lives in `src/main.go`.
- The module path is `witnsby/homebrew-aws-sso-login` (see `go.mod`).
- Go version: **1.23.4**.
- No external Go dependencies — only the standard library is used.
- Dependabot runs daily on `gomod` and weekly on `github-actions`.

## Testing Changes

```bash
make tests   # unit tests
make run     # dry-run the updater (writes to Formula/aws-sso-login.rb)
```

After running `make run`, inspect `Formula/aws-sso-login.rb` to verify the version, URLs, and SHA256 values are correct before committing.
